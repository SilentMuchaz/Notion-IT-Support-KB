# IT Support Knowledge Base — Service Desk Documentation Case Study

## Project summary

**Project type:** Self-initiated IT support simulation  
**Platform:** Notion  
**Focus:** First- and second-line support documentation, user lifecycle guidance, and service-desk processes  
**Knowledge base:** [Open in Notion](https://ultra-flock-9ab.notion.site/IT-Support-Knowledge-Base-243240fe1ebb80cba970d468bb65f345?pvs=73)

## Objective

I created a Notion-based knowledge base to organize common IT support topics into a centralized reference. The goal was to document repeatable support workflows and communicate technical guidance in a format suitable for first- and second-line support scenarios.

## Scope of the knowledge base

| Workstream | Documented topics | Relevance to IT support |
|---|---|---|
| Troubleshooting | Outlook, printer, and VPN issues | Repeatable diagnosis and end-user guidance |
| User lifecycle | Onboarding and offboarding | Consistent account and access workflows |
| Microsoft 365 | Administrative procedures | Support for common cloud productivity environments |
| Security awareness | User-facing security practices | Security-conscious support communication |
| Service management | Escalation and SLA references | Clearer incident handoffs and support expectations |

## Tools and methods

- **Notion** — Workspace for organizing and presenting support knowledge.
- **Microsoft 365** — Administration topics addressed in the knowledge base.
- **Active Directory concepts** — User and access-management knowledge used in the project scope.
- **ITIL principles** — Documentation and escalation concepts informing the service-desk approach.

The presence of Microsoft 365 and Active Directory topics does not, by itself, demonstrate live administrative changes to production systems.

## Deliverable and result

The primary deliverable is the [Notion IT Support Knowledge Base](https://ultra-flock-9ab.notion.site/IT-Support-Knowledge-Base-243240fe1ebb80cba970d468bb65f345?pvs=73), which the repository describes as containing troubleshooting guidance, user onboarding and offboarding workflows, Microsoft 365 procedures, security awareness guidance, and escalation/SLA documentation.

The project demonstrates the ability to **structure IT support information and communicate repeatable procedures**. It is a portfolio simulation; no production rollout, real ticket statistics, or measured resolution-time improvements are claimed.

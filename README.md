# 🖥️ IT Support Knowledge Base (Notion Project)

This project simulates a real-world internal IT knowledge base, designed for use in a 1st/2nd line support environment. Built using Notion, it includes:

## 📚 Features

- ✅ Step-by-step troubleshooting guides (Outlook, printers, VPN, etc.)
- 👤 User onboarding/offboarding workflows
- 🛠️ Microsoft 365 admin procedures
- 🧠 Security awareness & best practices
- 📈 Escalation and SLA documentation

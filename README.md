# IT Support Knowledge Base | Notion

**A self-initiated IT support documentation project designed around common first- and second-line service-desk workflows.** I used Notion to organize troubleshooting guidance, user lifecycle procedures, Microsoft 365 administration topics, security awareness, and escalation references in one knowledge base.

**[Explore the Notion knowledge base](https://ultra-flock-9ab.notion.site/IT-Support-Knowledge-Base-243240fe1ebb80cba970d468bb65f345?pvs=73)** · [Project case study](IT-Support-Knowledge-Base-Case-Study.md) · [PDF overview](reports/01-it-support-knowledge-base-case-study.pdf)

## Project overview

The objective was to create a centralized reference for repeatable support scenarios, with clear written procedures and service-desk guidance. This is a **self-initiated simulation**, not a claim of deployment in a production IT department.

## What I documented

| Area | Knowledge-base coverage |
|---|---|
| **Troubleshooting** | Common Outlook, printer, and VPN support scenarios |
| **User lifecycle** | User onboarding and offboarding workflows |
| **Microsoft 365** | Administrative procedures and support guidance |
| **Security awareness** | Security practices and user-focused guidance |
| **Service management** | Escalation paths and SLA-related documentation |

## Tools and approaches

- **Notion:** Knowledge-base organization and technical documentation.
- **Microsoft 365 and Active Directory:** Administration and user-management concepts covered by the project.
- **ITIL principles:** Service-desk process, escalation, and documentation approach.

**Scope:** This is a simulated service-desk knowledge base, not a production deployment.
